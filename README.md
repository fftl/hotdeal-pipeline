# Hotdeal-pipeline

## Hotdeal 자동 수집 프로젝트
>각종 사이트에서 확인할 수 있는 핫딜 게시글들의 정보를 즐겨보는데, 매번 사이트에 직접 방문해서 게시글을 확인하는 것이 아니라, 데이터를 수집하는 것은 어떨까 하는 생각에 진행하게 되었습니다.

여러 핫딜 커뮤니티의 RSS 피드를 주기적으로 수집해 데이터 웨어하우스에 raw데이터를 축적하고, 계층형 변환을 거쳐 대시보드로 소비하기까지의 전 과정이 자동으로 작동하도록 만들었습니다.

## 기술 스택
- Python, Airflow, DBT, BigQuery, Looker Studio

## 무엇을 (What)
RSS를 통해 수집할 수 있는 핫딜 데이터들을 수집합니다.
